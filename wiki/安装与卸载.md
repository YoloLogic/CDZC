# 💾 安装与卸载

## 安装

双击 `CDZC-0.1-Setup.exe`，向导会依次问：

| 步骤 | 说明 | 默认 |
|---|---|---|
| 安装位置 | 默认 `%LOCALAPPDATA%\中文大战代码`，**不需要管理员权限** | 默认 |
| 附加任务 | 桌面快捷方式 / 开始菜单 / 加入 PATH / 右键菜单 | **全部勾选** |
| 安装 | 约 1.7 GB，2 分钟左右 | |
| 完成 | 可勾选「立即启动」 | |

安装完你会得到：

```text
桌面      中文大战代码（红底「中」图标 → editor\中文大战代码.exe）
开始菜单  中文大战代码
          中文大战代码（游戏引擎）
          示例工程
          终端（已配好工具链）
          卸载 中文大战代码
应用列表  中文大战代码 0.1（约 1699 MB）
```

### 静默安装

```powershell
.\CDZC-0.1-Setup.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART /SP- `
  /DIR="D:\中文大战代码" /TASKS="desktopicon,startmenu,addtopath,shellmenu"
```

`/TASKS=""` 则不建快捷方式、不加 PATH。

## 环境要求

| 项 | 要求 |
|---|---|
| 系统 | Windows 10/11 **x64** |
| **C++** | **Visual Studio Build Tools / Windows SDK**（MSVC STL + UCRT） |
| Python / Java / TypeScript | **无额外依赖** |
| 磁盘 | 约 1.7 GB |

> [!IMPORTANT]
> 为什么 C++ 要装 VS Build Tools：当前发行版用 `mode = system`，
> "不依赖 Visual Studio 的自足底座"尚未完成（设成 bundled 时仍有 243 个 Windows SDK 头来自 `C:\Program Files (x86)\Windows Kits\`）。

## 卸载

从「设置 → 应用」或开始菜单的「卸载 中文大战代码」。

卸载会清掉：**安装目录（含 1.7 GB 工具链）、桌面快捷方式、开始菜单项、应用列表登记项、
以及写进 PATH 的 5 条工具链条目** —— 不留残余。

> [!NOTE]
> 卸载**不动**你的个人配置：`%APPDATA%\中文大战代码`（编辑器设置、最近打开）会留着，
> 想彻底清就手动删掉它。
