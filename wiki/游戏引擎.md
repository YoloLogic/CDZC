# 🎮 游戏引擎

## 它是什么

**魔改 Godot 4.7.2**（`4.7.2.stable.custom_build`），界面中文，与编辑器**同名同品牌**。

```text
engine\中文大战代码.exe            引擎本体（约 158 MB）
engine\中文大战代码_console.exe    带控制台输出版本（调试用）
engine\addons\py4godot\            自带 ChinesePython（GDExtension）
engine\打开编辑器.cmd              引擎 → 编辑器的桥接
```

## 引擎里也能写中文

引擎**自带 ChinesePython**：`engine\addons\py4godot\cpython-3.14.7-windows64\python\`
下有 `pythonscript.dll`（GDExtension）、`python314.dll`、`Lib\`（中文标准库）。

实测（用引擎自带那份跑）：

```text
版本 3.14.7
平方根(16) = 4.0
圆周率 = 3.141592653589793
阶乘(5) = 120
中文报错 = 除零错误: 除以零
```

### 三条硬约束（决定了它只能这样放）

1. **GDExtension 的 `.dll` 必须是磁盘上的真实文件** —— 操作系统要 `dlopen` 它；
   Godot 的 `.pck` 是资源包，装不了可执行代码。
2. **CPython 用文件系统接口导入模块** —— `res://` 虚拟路径它打不开。
   所以 `python314.dll`、`Lib\`、`.py` 脚本**都必须在磁盘上**（导出游戏时也要一起发出去）。
3. **中文关键字编在 `python314.dll` 里** —— 换 Python = **换这个 dll + 换 `Lib\`**，两者必须配套。

<details>
<summary><b>怎么升级 / 更换引擎内的 Python</b></summary>

```powershell
$引擎Python = 'engine\addons\py4godot\cpython-3.14.7-windows64\python'
# 1) 换 dll（中文关键字在这里）
Copy-Item <新ChinesePython>\PCbuild\amd64\python314.dll $引擎Python -Force
# 2) 换标准库（必须与 dll 配套）
robocopy <新ChinesePython>\Lib "$引擎Python\Lib" /E /XD test __pycache__
```

</details>

## 双向联动

```text
┌──────────────────┐   「游戏引擎」按钮        ┌──────────────────┐
│  代码编辑器       │ ───────────────────────▶ │  游戏引擎         │
│  中文大战代码     │                          │  中文大战代码     │
│                  │ ◀─────────────────────── │                  │
└──────────────────┘   引擎内打开脚本          └──────────────────┘
```

- **编辑器 → 引擎**：右下角「游戏引擎」按钮，按 `engine\中文大战代码.exe` 找引擎，
  以 `--editor --path <当前项目>` 打开；
- **引擎 → 编辑器**：引擎的「外部编辑器」已被自动指向 `engine\打开编辑器.cmd`，
  点开脚本就进我们的编辑器并定位到行。

> [!TIP]
> 这两条都实测过：从**安装目录**里跑，引擎能找到、编辑器能被唤起（进程可执行文件路径就在安装目录内）。

## 引擎内置脚本编辑器 = 我们的编辑器

这是**改 Godot 源码**做的两处：

| 改动 | 位置 |
|---|---|
| `text_editor/external/use_external_editor` 默认 `false` → **`true`** | `editor\settings\editor_settings.cpp` |
| `exec_path` 为空时回落到**引擎同目录的 `打开编辑器.cmd`** | `editor\script\script_editor_plugin.cpp` |

效果：双击脚本不再打开 Godot 内置编辑器，而是**直接进中文大战代码**，且**用户不需要配置任何路径**。
