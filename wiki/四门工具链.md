# 🧰 四门工具链

## 一览

| 语言 | 位置 | 版本 / 说明 |
|---|---|---|
| **C/C++** | `toolchains\cpp\bin\chinese++.exe` | Chinese++（Clang fork），C++20 / C17 |
| **Python** | `toolchains\python\PCbuild\amd64\python.exe` | ChinesePython 3.14.7 |
| **Java** | `toolchains\java\runtime\bin\javac.exe` | ChineseJava（只汉化关键字与诊断） |
| **TypeScript** | `toolchains\typescript\bin\chtsc.exe` | ChineseTypeScript 0.2.4（自带 node） |

## 写起来长什么样

```cpp
// C++  —— 整数 主函数()
#包含 <C标准输入输出>
整数 主函数() { 标准::格式化输出("你好\n"); 返回 0; }
```

```c
// C  —— 整数 主函数(空型)，编译时要 -x c
#包含 <C标准输入输出>
整数 主函数(空型) { 标准::格式化输出("你好\n"); 返回 0; }
```

```python
# Python
定义 斐波那契(第几项):
    如果 第几项 <= 1: 返回 第几项
    返回 斐波那契(第几项 - 1) + 斐波那契(第几项 - 2)
```

```java
// Java（只汉化关键字，标准库名保持英文）
公开 类型 你好 { 公开 静态 空型 main(String[] 参数) { System.out.println("你好"); } }
```

```ts
// TypeScript
常量 问候: 字符串 = "你好";
控制台.日志(问候);
```

> [!WARNING]
> **TypeScript 的 `属于` 是 `for...in`（下标，字符串），不是 for-of。**
> 遍历数组请用 `遍历`。

## 运行

### 编辑器里（推荐）

打开 `examples\` 下任一目录 → <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>B</kbd> → 选对应任务。

### 命令行

```powershell
# 让本窗口看到四门工具链（不改系统环境）
<安装目录>\启动.cmd        # 或手动：
$env:PATH = "<安装目录>\toolchains\cpp\bin;<安装目录>\toolchains\python\PCbuild\amd64;<安装目录>\toolchains\java\runtime\bin;<安装目录>\toolchains\typescript\bin;<安装目录>\toolchains\typescript\node;" + $env:PATH
$env:PYTHONHOME = "<安装目录>\toolchains\python"

chinese++ -std=c++20 你好.cpp -o 你好.exe ; .\你好.exe
python 你好.py
javac 你好.java ; java 你好
chtsc 你好.ts --target es2020 ; node 你好.js
```

<details>
<summary><b>C++ 的 9 个别名与 3 份 cfg 是什么</b></summary>

- **9 个二进制名**：`clang.exe` / `clang++.exe` / `clang-cl.exe` / `clang-cpp.exe` /
  `lld.exe` / `ld.lld.exe` / `wasm-ld.exe` / `llvm-lib.exe` / `llvm-ranlib.exe`
  —— 它们是硬链接（ZIP 不保留，装完由安装器重建）；
- **3 份 cfg**：`bin\chinese++.cfg` / `clang++.cfg` / `clang.cfg`，内容是 5 条中文头搜索路径
  （**绝对路径** ⇒ 移动安装目录后要重跑生成）。

</details>
