# 🖥️ 代码编辑器

## 它是什么

基于 **VS Code 1.142** 的分支，**界面中文是编译进产品的**（NLS 资源 + 随包语言包），不是外挂翻译。

```text
编辑器  editor\中文大战代码.exe
数据目录 %APPDATA%\中文大战代码
```

## 打开就是中文

- 标题栏、菜单、右键菜单、设置项、欢迎页全中文；
- 语言包 `vscode-language-pack-zh-hans` 随包，且**路径在运行时重算** —— 装到任何目录、任何盘符都是首次启动就中文
  （早期版本把绝对路径写进 `languagepacks.json`，换机就变英文，已修）。

## 内置扩展（4 个）

| 扩展 | 作用 |
|---|---|
| `cdzc-authentication` | 「登录中文大战代码」：设备码流程走自有账号，状态栏显示登录态 |
| `cdzc-languages` | `zh-cpp` / `zh-python` / `zh-java` 的语法高亮（中文关键字不标红） |
| `cdzc-toolchains` | 启动时把四门工具链的 PATH / `PYTHONHOME` / `CDZC_ROOT` 注入**终端**（不改系统环境） |
| `cdzcgodot` | 「游戏引擎」按钮：拉起引擎打开当前项目；并把引擎的外部编辑器指向本产品 |

## 示例与任务

打开 `examples\` 下任一目录，按 <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>B</kbd>：

| 任务 | 作用 |
|---|---|
| C++：编译并运行 | `chinese++ -std=c++20`（**不需要 `-I`**，中文头由 `bin\*.cfg` 提供） |
| Python：运行 | `python 你好.py` |
| Java：编译并运行 | `javac` + `java` |
| TypeScript：编译并运行 | `chtsc` + `node` |

## 有意的边界

> [!NOTE]
> **没有扩展市场、不登录微软/GitHub 账号** —— 这是产品决定（规避微软服务条款），
> 登录走自有账号体系，与编辑器无关的功能一律不接。
